## 10 Second Clicker Game
Josue Hernandez assignment a4-components

https://a4-components-7i5n.onrender.com/

I rebuilt the client side of my A2 clicker game, plus some of A3, as React components (e.g., Header, LeaderBoard, Game, and LoginScreen), using Express, MongoDB, and GitHub login. React improved development overall, because state replaced all my manual DOM code, which made the game logic much easier to manage. It took some time at first, especially learning how to conditionally render content while sending API requests. But the finished code is short, and App.jsx looks really simple.
